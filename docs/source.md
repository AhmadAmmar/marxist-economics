# LaTeX source

The authoritative LaTeX source files live in the repository's `latex/` folder.

Core files:

- `latex/main.tex`
- `latex/preamble.tex`
- `latex/content.tex`
- `latex/notation.tex`
- `latex/glossary.tex`
- `latex/bibliography.tex`

No duplicate LaTeX source folder is needed under `docs/assets/`.
