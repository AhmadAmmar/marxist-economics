# Help improve this pamphlet

This is an open project, and you don't need to know any code to take part.

## Without a GitHub account

[Email the author](mailto:ahmadammargeo@gmail.com?subject=Marxian%20Economics%20101) with the page and what you noticed.

## With a free GitHub account

An *issue* is a public note about something to fix or discuss. Anyone can open one, and it takes a minute.

- [Report an error](https://github.com/AhmadAmmar/marxist-economics/issues/new?template=error.yml): a wrong number, a broken link, a faulty derivation or a misattributed quote.
- [Suggest an improvement](https://github.com/AhmadAmmar/marxist-economics/issues/new?template=idea.yml): a clearer explanation, a new example or a translation.
- [Discuss the ideas](https://github.com/AhmadAmmar/marxist-economics/discussions): questions and disagreements about the argument are welcome.

## Propose a change directly

If you are comfortable with GitHub, edit the LaTeX in `latex/` and open a pull request. The site rebuilds from that source, and the checks run automatically. See the [guide to how the project is built](how-it-works.md) and the [contributing notes](https://github.com/AhmadAmmar/marxist-economics/blob/main/CONTRIBUTING.md).

Please quote sources and be specific. Comradely disagreement is welcome, and personal attacks are not.
